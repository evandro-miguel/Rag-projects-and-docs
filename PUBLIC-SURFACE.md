# Public surface

This standalone repository is a product-only snapshot of source commit
`9b634e10334202fe6b64209394e24f7d8df461af`.

## Included

- Product CLI, MCP server, shared libraries, operational scripts, and tests.
- Docker and database assets, ingestion prompts, and standalone root `skills/`.
- Bun, TypeScript, Vitest, and Biome configuration plus the lockfile.
- The public README, license, security and support policies, guides, and the
  active reranker benchmark scenario.

## Excluded

- AFOL and agent governance, workbench state, local agent configuration, and
  repository operating instructions.
- Generated runtime data, temporary files, caches, local environment files,
  and generated external documentation corpora.
- Internal, archived, legacy, telemetry, roadmap, and governance documents.
- Host-specific Codex, Claude, and OpenCode configuration.

The package metadata remains private; this repository does not claim npm
publication or hosted-service readiness.
