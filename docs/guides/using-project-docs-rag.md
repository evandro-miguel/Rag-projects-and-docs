# Project Docs RAG status

Project Docs RAG would search local repository documents such as READMEs and
documentation while keeping them separate from external Docs RAG and
repository-code Project RAG records.

This surface is planned and is not implemented in the current alpha. There is
no supported local-document sync or search command. The existing deprecated
`search_project_docs` name remains an alias for Project RAG code search; it
does not search local documents.
